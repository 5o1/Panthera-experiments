# Panthera v2 单次抓取、连续搬运与直接释放修复

日期：2026-09-16

状态：历史修复阶段。实现和 2 条录制 smoke 已通过；18 组广域回归为 16/18。其后的
schema 10 正式数据集已经完成，见
[正式数据集报告](15_panthera_v2_formal_dataset_2026-09-16.md)。

## 1. 本次修复的问题

旧 `v2_symmetric_smooth_pilot` 有两个不能进入训练的问题：

1. 规划器报告的内部近零速度很少，但 HDF5 中的**实际关节位置**和人工视频仍显示抓取后
   周期性停顿。旧验收只检查规划速度，不能证明仿真机械臂真的连续运动。
2. 平躺圆柱先被转正并放回桌面，再由顶部二次抓取，动作冗长，也给策略引入了不必要的
   中间状态。

旧 64 条数据及其审阅视频因此保留为失败证据，不得继续用于 RLDS 或训练。

## 2. 连续运动实现

完整持物路线现在先生成稠密关节几何路径，再进行四轮 Chaikin 局部凸组合，削弱相邻 IK
段之间的尖角。平滑路径逐点检查自碰撞和环境碰撞，之后只做一次 TOPP 时间参数化，并由
一次 `take_dense_action` 执行。抬升、转腕、横移和下降属于同一条轨迹，中间笛卡尔路点不再
构成停止命令。

验收改为读取 HDF5 的：

- `observation/robot_state/arm_qpos`
- `timing/simulation_step_index`
- `timing/simulation_time_s`

只分析 `continuous_motion_audit` 标出的持物路线区间。在首次和末次实际速度达到
`0.02 rad/s` 之间，统计低于该门槛的连续时段；任何达到 `80 ms` 的内部停顿都会使新
pilot 验收失败。规划器速度仍作为辅助审计，不再作为主要证据。

## 3. 单次抓取与直接释放

平躺圆柱不再从中心夹持，而是沿圆柱物理轴向一端偏移 `44 mm`。圆柱半长为 `60 mm`，
因此抓点离端面仍保留 `16 mm`。夹住后始终保持同一个刚体接触关系，在空中把圆柱轴旋转
至竖直，同时搬运到槽口；不再放回桌面，也不再调用第二次抓取。

在机械臂接触圆柱以前，oracle 会预检“圆柱两端 × 两种转正径向”的有限候选。候选必须让
预抓取、抓取以及完整持物路线全部可规划，才允许开始真实仿真动作，避免抓到一半才发现
后续路线不可达。

释放位置用圆柱底面相对槽口顶面的高度定义。搜索中共同可用的最低值为 `-15 mm`；正式值
取 `-14 mm`，即保留 `1 mm` 容错。夹爪在该位置打开，圆柱靠重力完成最后落座，然后夹爪
撤离。接触求解迭代和圆柱阻尼只在持物路线结束后启用，避免改变抓取与搬运动力学。成功
路径不使用墙钟 `sleep`。

## 4. 验证结果

最终录制 smoke 使用 seed 0（直立）和 seed 1（平躺），采集器为 `2/2` 成功、`0` 次
失败。每个 episode 只包含一条本集的连续运动审计，修复了 RoboTwin 复用 task object 时
审计列表串到下一集的问题。

| 指标 | 直立 episode 0 | 平躺 episode 1 |
| --- | ---: | ---: |
| 单次抓取 | 是 | 是 |
| 持物路线时长 | 7.18 s | 12.84 s |
| 实际内部近零速比例 | 0 | 0 |
| 最长实际内部近零速段 | 0 s | 0 s |
| ≥80 ms 内部停顿 | 0 | 0 |
| 实际关节速度 P05/P50/P95 | 0.063/0.408/0.852 rad/s | 0.103/0.486/0.775 rad/s |
| 平躺轴向抓取偏移 | 不适用 | 44 mm |

另做了 18 组广域回归（8 个平躺角度区间各两个 seed，加两个直立 seed）。所有 18 组都
完成规划并把圆柱放入槽内，严格稳定判定通过 `16/18`。bin 4/seed 6 与 bin 7/seed 6 的
最终位置、插入深度、竖直角度和夹爪释放均满足几何条件，但在 10 秒仿真窗口结束时仍有
约 `0.06 m/s` 线速度和 `1 rad/s` 角速度，故按接触稳定门槛判失败。这是尚待处理的
PhysX 槽内接触抖动，不能写成 18/18 成功。
