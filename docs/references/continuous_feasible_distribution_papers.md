# 连续可接受状态与多解动作分布论文索引

检索日期：2026-09-24

本索引服务于 Panthera 单臂圆柱入槽任务中的一个一般问题：训练目标能否从离散专家样本，
扩展为连续状态空间上的成功/可行性分布，以及给定状态下覆盖多个有效动作或轨迹的条件分布。
检索没有从某个机器人模型名开始，而是依次覆盖条件密度估计、集合值/多模态回归、概率预测
校准、流形平滑、可生存状态—动作集合、机器人可行性学习、模仿学习分布偏移和生成式策略。

## 选择边界

- 前六篇回答一般监督学习怎样表示多值输出、条件分布及其校准，而不依赖机器人语境。
- 中间四篇把集合和概率观点连接到控制、状态—动作可生存域与可行性分类。
- 后六篇说明专家状态分布偏移、能量模型、扩散动作序列和“全部可行动作”怎样进入机器人策略。
- 2026 年的超水平集回归是新预印本，只用来说明直接学习复杂条件区域的最新方向，不作为
  已被机器人实验充分验证的工程结论。
- 这些论文没有直接复现 Panthera 的“到位不松爪”故障。报告中的项目方案是基于文献与现有
  trace 的研究假设，仍需仿真消融验证。
