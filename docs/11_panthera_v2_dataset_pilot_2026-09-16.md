## 1. 数据集目标

当前任务只有一台固定基座的 Panthera 机械臂和一个夹爪。每条轨迹需要抓取一个圆柱，
必要时先将其从平躺姿态转为直立姿态，再把它竖直插入凹槽。数据的外部 observation 和
action 都保持 7 维：`joint1..joint6` 加一个归一化夹爪量。

本轮不沿用旧数据集的固定物体布局，而是独立随机圆柱和凹槽的位置。采样区域以机械臂
基座 `(0, -0.35) m` 为圆心，使用任务实测有效半径 `0.46 m` 的 75%，即最大半径
`0.345 m`；最小半径为 `0.22 m`，角度范围为 `90°..175°`，圆柱与凹槽的最小间距为
`0.16 m`。这里的 `0.46 m` 是当前抓取和插入流程能够稳定工作的任务半径，不宣称是机械臂
连杆决定的理论最大可达距离。

## 2. 姿态与轨迹生成

64 条成功轨迹按姿态严格分层：

- 32 条圆柱初始直立；
- 32 条圆柱初始平躺；
- 平躺方向划分为 8 个角度区间，每个区间恰好 4 条。

直立圆柱使用顶部抓取、抬升、搬运、插入流程。平躺圆柱使用侧向抓取，在固定重定向区域
通过腕部真实旋转将圆柱转为竖直，低位释放后退夹，再从顶部重新抓取，抬升并插入凹槽。
成功路径没有使用 D6 抓取附着或物体瞬移，也没有用墙钟 `sleep` 采集轨迹；控制和记录由
仿真步推进。

## 3. 验收结果

| 项目 | 结果 |
| --- | --- |
| 成功 episode | 64 |
| 唯一 seed | 64 |
| 姿态分布 | 直立 32 / 平躺 32 |
| 平躺角度分布 | 8 个区间各 4 条 |
| 圆柱位置网格覆盖 | 33 / 36 |
| 凹槽位置网格覆盖 | 18 / 36 |
| 单集原始帧数 | 869–2716 |
| observation/action | 均为有限值的 7 维向量 |
| 训练是否启动 | 否 |

采集器为了保持姿态和角度配额，只把物理执行成功的 seed 写入数据集。找到 64 条成功轨迹
期间另有 64 次规划或执行失败，因此本轮候选成功率是 `64/128 = 50%`。各分片失败数为
`[1, 1, 0, 2, 8, 5, 2, 9, 5, 10, 2, 19]`。成功集本身没有失败轨迹，但这种成功筛选
会使数据分布偏向 oracle 容易完成的位置；凹槽只覆盖 18/36 个位置网格也说明 pilot 尚不
适合作为最终训练集。后续扩大数据前，应先根据人工视频审阅结果改善平躺重抓流程和凹槽
覆盖，而不是直接增加同分布样本。
