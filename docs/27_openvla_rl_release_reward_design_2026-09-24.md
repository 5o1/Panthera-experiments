# OpenVLA 释放切换强化学习奖励设计

日期：2026-09-24

## 1. 要回答的问题

当前 DDP 修复后的 28 维 OpenVLA-OFT `step 75000` 是唯一在同一 episode 2 上同时通过
`h20` 和逐步滑动平均闭环的候选。它证明策略有时能够完成整项任务，但其他 checkpoint 和
rollout 仍会出现两类失败：形成有效夹持前抖动并撞开圆柱，以及把圆柱送到正确释放位后
仍把夹爪保持在约 0.30。专家帧上模型能够生成连续开爪斜坡，所以问题不是夹爪动作头从未
学过打开，而是自主闭环偏离后没有可靠触发释放过程。

本阶段要检验的命题是：**不给策略显式阶段标签，也不奖励某个夹爪动作数值，只根据动作
造成的物理后果，强化学习能否学会何时保持、何时释放。** 仿真特权状态只允许用于计算
训练奖励和验收，不进入策略 observation；否则成功不能迁移到真实工作台。

## 2. 前人工作给出的边界

### 2.1 稀疏终局奖励最干净，但探索可能不可行

HER 说明稀疏目标奖励可以通过把失败轨迹重新解释为其他目标来提高样本效率；反向课程则
从成功状态附近开始，并逐渐把初始状态向更早处扩展。Nair 等人进一步在长时域连续机器人
任务中使用示范、示范状态重置和辅助模仿损失解决探索问题。三者共同支持：先从“已夹持且
接近释放位”的快照训练，再向搬运和完整 reset 反向扩展，而不是要求策略从第一轮随机探索
就发现整条抓取—搬运—释放链。

### 2.2 稠密奖励不能直接奖励动作

Ng、Harada 与 Russell 证明，按

```text
F(s, s') = gamma * Phi(s') - Phi(s)
```

添加势函数差分，在标准 MDP 条件下能够保持原最优策略；任意手写逐步奖励则可能改变最优
解。Panthera 是视觉部分可观测任务，且存在 episode 截断，所以该定理不能直接当作本项目
保证，但它仍给出最安全的稠密化原则：奖励“剩余任务成本下降”，不要奖励“执行了某个
动作”。尤其不能用 `gripper > 0.5` 加分；那会把专家释放标签写回奖励，并鼓励提前开爪。

### 2.3 显式阶段奖励有效，但不能证明自主发现切换

robosuite 的 pick-place 奖励把 reaching、grasping、lifting、hovering 分段，并让完整成功
仍取得最高分。Reward Machines、STARE-VLA 和 VLA-RL 也显式暴露奖励结构或从轨迹分段产生
过程奖励；VLA-RL 甚至使用夹爪开度显著变化和末端低速关键帧构造伪标签。这些工作说明阶段
奖励是强基线，但若 Panthera 使用同样方式成功，只能说明“写明阶段后能学”，不能说明
模型自己发现了释放时机。因此显式阶段奖励只作为诊断上界，不作为主实验。

### 2.4 只奖励子任务完成还不够，必须奖励交接质量

2026 年的 Foresight Residual RL 在抓取、移动插入、旋转三阶段装配中报告：固定的子任务
成功奖励能提高单项技能，却未同步提高完整任务；对当前阶段终态加入后续阶段成功概率后，
完整成功率才从其标准子任务残差 RL 的 54.5% 提高到 85.6%。这是一篇单任务仿真预印本，
不能直接外推到 Panthera，但它直接提醒本任务：`到达槽上方`、`夹爪已打开` 都不能单独算
成功，释放奖励必须依赖圆柱随后稳定进入槽这一后续结果。

### 2.5 用残差策略保护已经会做的部分

Residual RL 把学习动作叠加到已有控制器上，在接触丰富的真实装配中学习原控制器不会的
修正。对 Panthera 而言，当前 SFT 已经具备条件稳定的持物搬运能力；第一轮 RL 不应解冻
整个 7B 模型并冒险破坏它。更可控的方案是冻结 VLA 主干和基准动作，先学习有界随机残差
头，并用相对基准的 KL/残差范数限制漂移。

### 2.6 动作分块不自动保证跨 chunk 一致

ACT 用推理时 temporal ensemble 平均对同一绝对时刻的重叠预测；这是执行器侧聚合，不是
训练时的跨 chunk 一致性损失。2025 年 Action-Chunked PPO 工作则在 PPO 外增加由策略
自采高质量轨迹形成的辅助行为克隆损失，并动态调节两者权重，以稳定 VLA 的 RL 后训练。

更直接的证据来自 2026 年预印本 ChunkFlow：策略接收最近动作历史；相邻 chunk 的重叠区
使用边界误差；chunk 内另加一阶 total variation 与二阶曲率损失；训练时对历史加入噪声、
dropout 和 scheduled sampling；AWAC 微调时继续保留这些结构正则。它几乎对应“加入上一
chunk 并加 consistency loss”的完整版本。RTC、Soft RTC 与 SEAM 也都利用上一 chunk 已
提交的动作或未执行尾部约束新 chunk，但主要面向 diffusion/flow 动作头。Panthera 当前的
连续 L1/高斯残差头不能直接复制 denoising/inpainting，只能迁移历史条件和对齐边界思想。

这些工作共同说明“输出一个 chunk”本身不足以保证相邻查询一致。ChunkFlow 是目前最直接
的实现证据，但仍是单篇预印本，不能据此预先宣称 Panthera 抖动必然解决。

当前 RL 方案虽然没有逐步专家动作损失，仍保留冻结 SFT 基线、相对基线 KL 和有界残差；
这些约束限制整体策略漂移，却不直接约束相邻观测对同一未来时刻给出相容预测。应补充
跨 chunk 重叠一致性作为独立训练轴，同时保留无此损失的对照。恒定输出也能取得零一致性
损失，所以它只能负责“连续”，任务奖励仍必须负责“正确”。

## 3. 奖励定义

### 3.1 原始任务奖励

任务奖励只评价最终物理结果：

- `+1`：圆柱满足现有 `check_success()` 的位置、姿态和插入条件，夹爪已解除接触，并在
  现有 settle 判据要求的连续物理步内保持低线速度和低角速度；只发放一次并终止 episode。
- `-1`：圆柱离开可恢复工作区、在合法释放区外丢失且已不可恢复，或发生现有任务定义的
  硬失败；只发放一次并终止 episode。
- 其他状态为 `0`。仅到达槽上方、仅张开夹爪、圆柱仍被夹持，均不是成功。

稳定计数器属于奖励环境内部状态，不作为策略输入。阈值全部复用 task config 和现有成功
判据，禁止再复制一套相近但不同的常数。

### 3.2 推荐的效果型势函数塑形

主实验使用：

```text
r_t = r_task
    + eta * (gamma * Phi(s_{t+1}) - Phi(s_t))
    - lambda_arm * arm_action_change_t
    - lambda_time
```

`Phi(s) = -C_remaining(s)`，其中 `C_remaining` 是根据**实际物理状态**估计的剩余成本：

1. 尚未可靠夹持：末端到圆柱的归一化距离，加上尚未完成的夹持、搬运和释放成本；
2. 已可靠夹持：圆柱到合法释放体积的位置误差、轴向误差和高度误差，加上释放后沉降成本；
3. 在合法体积内解除接触：圆柱到最终入槽状态的位置/姿态误差和速度；
4. 成功吸收态：剩余成本为零。

这些模式来自接触、物体随夹爪运动、几何误差和物体速度，不来自专家时间步或人工 phase
标签。各模式间加入连续偏置，使正确交接降低剩余成本，而槽外丢失会增加剩余成本；否则
策略可能通过反复夹持/松开利用势函数跳变刷分。

初始数值只规定相对量级，不凭空锁死距离权重：把 `Phi` 归一化到 `[-0.25, 0]`，使一次
完整塑形收益最多约为终局成功的四分之一；整条 episode 的时间代价不超过 `0.02`，机械臂
六关节动作变化惩罚不超过 `0.05`。夹爪维不使用同等平滑惩罚，因为正确释放本来就要求其
持续变化。成功奖励始终占主导，避免策略为了少动而停住，或为了赶时间在圆柱附近加速碰撞。

### 3.3 明确禁止的奖励

- 禁止因夹爪目标超过 0.5、夹爪变化方向或某个专家 row 而加分；
- 禁止圆柱到达槽上方但仍被夹住时判成功；
- 禁止每一步重复发放“已抓住”“已到位”等绝对奖励；若做阶段上界，必须用一次性 latch；
- 禁止使用历史最小距离直接逐步加分；当前 `_Progress` 中的 nearest/max 指标适合报告，
  但直接当奖励会非 Markov 且容易刷分；
- 禁止把仿真圆柱真值加入策略 observation；它只服务奖励、课程采样和验收。

### 3.4 跨 chunk 重叠一致性损失

设策略在查询时刻 `t` 输出长度为 `H=25` 的均值动作块 `mu_t[0:H]`，执行 `d` 步后再次
查询。`mu_t[d+j]` 与 `mu_(t+d)[j]` 都指向同一个绝对执行时刻，因此只对这些对齐项计算：

```text
L_overlap = weighted_mean_j(
    Huber(normalize(mu_t[d+j] - mu_(t+d)[j]))
),  j = 0 .. H-d-1
```

这里比较连续随机策略的**分布均值**，不比较实际采样动作；否则探索噪声本身会被当成
错误。`normalize` 使用动作合同的逐维尺度，避免弧度与归一化夹爪量互相支配。跨 episode、
reset、终止之后和没有真实重叠的项必须 mask。公式必须使用实际查询间隔 `d`，不能硬编码
为一帧；`h1` 有 24 个重叠项，`h20` 只有 5 个。

总策略目标变为：

```text
L_policy = L_PPO
         + beta_kl * KL(policy || frozen_SFT)
         + beta_residual * L_residual
         + beta_overlap * L_overlap
```

仅有该损失还没有实现学长建议中的“加入上一个 chunk”。完整主候选再向残差/refiner 输入：

1. 最近真实执行的短动作历史；
2. 上一 chunk 中尚未执行、且与当前 chunk 指向同一绝对时刻的尾部；
3. 标明哪些位置真实有效的 overlap mask；
4. 当前图像、28 维 proprio 和冻结 SFT 输出的当前 raw chunk。

不能无条件输入完整旧 chunk：其中已经执行的前缀是历史，而较远、从未执行且不再重叠的
预测是过期计划。下一轮训练历史应来自 post-blending 的真实执行动作，并按 ChunkFlow 加入
噪声、dropout 和 scheduled sampling；否则 refiner 只在完美旧计划上训练，部署时会把旧
错误循环反馈。

六个机械臂维度可以按 ChunkFlow 用上一尾部 `stop-gradient` 作为边界目标，并同时测试
低权重一阶/二阶连续性。夹爪维不能默认同权加入：释放是接触模式切换，较新观测可能合理地
推翻旧预测；过强的旧 chunk 教师会把当前约 0.30 的闭合固定点固化。夹爪一致性应作为更晚
的独立消融，使用较小权重，并报告释放触发延迟。temporal ensemble 的平均结果不作为训练
标签。

一致性权重不得凭主观固定。先在短 smoke 中扫描到“重叠预测误差和边界 jerk 明显下降，
但 SFT 基线完整任务成功率及释放触发率不下降”的最小权重；随后锁定配置进入三 seed
实验。训练批次需要保存 `episode_id`、查询绝对步、实际查询间隔和有效重叠 mask，不能在
打乱 minibatch 后把无关 chunk 配成一对。

## 4. 奖励与一致性的同口径对照

从同一个 `step 75000`、同一组初始状态和训练预算开始：

| 组别 | 奖励 | 回答的问题 |
|---|---|---|
| `R0` | 原 SFT，不做 RL | 基准成功率和失败分布 |
| `R1` | 只有终局成功/硬失败 | 模型能否真正从结果奖励自行发现切换 |
| `R2` | `R1` + 效果型势函数差分 | 不指定动作时，物理进度能否解决信用分配；主候选 |
| `R3` | 显式 grasp/transport/release Reward Machine | 把阶段写进奖励后的诊断上界 |

`R3` 成功而 `R1/R2` 失败，说明需要更强的阶段监督；`R2` 成功则更符合用户提出的“模型自己
学切换”。不得只运行 `R3` 后声称强化学习自主学会了释放。

一致性是与奖励正交的第二个实验轴：

| 组别 | 一致性项 | 用途 |
|---|---|---|
| `C0` | 无跨 chunk 损失 | 判断奖励本身能否学习，防止把所有变化错误归因于一致性 |
| `C1` | 六关节对齐重叠一致性，不输入旧 chunk | 隔离 consistency loss 本身的作用 |
| `C2` | 执行动作历史 + 对齐旧尾部 + `C1` + 历史扰动 | 学长建议的完整主候选 |
| `C3` | `C2` 加低权重夹爪一致性 | 仅作释放消融，检查是改善触发还是固化闭合 |

短 smoke 比较 `R2-C0/C1/C2`，分别隔离无正则、只有 loss、history+loss；只有胜者进入
完整三 seed 训练。`R2-C3` 仅在主候选不损害释放后运行。`R0` 不重新训练，但必须用同一
release arena、初始状态、推理 wrapper 和动作预算重新评测；它不存在训练一致性项。

## 5. 反向课程，而不是从完整任务盲目探索

### 5.1 Release arena

从成功专家回放或 simulator snapshot 建立三层初始状态，并混在同一训练批次：

- 圆柱已可靠夹持且处于合法释放体积内：应学会松开并让物体稳定入槽；
- 已夹持、接近但仍在释放体积外：应先校正位置/姿态，不能立即松开；
- 已夹持且仍在搬运途中：应继续保持，不能学成“一启动就开爪”。

三层都随机扰动末端位置、圆柱姿态、夹持开度和动力学状态，但第一轮保持 episode 2 相机与
场景不变，以隔离奖励和切换本身。训练采样优先放在成功率约 50% 的边界状态；当 release
arena 的独立验证集达到门槛后，才把 reset 向搬运中段、抓取后、完整任务逐级前移。

### 5.2 Full task

完整任务阶段保留 release arena 的一定比例，防止后续长时域训练遗忘释放；其余从正常
随机 reset 开始。最终必须在未参与课程调节的固定 seed 上评估，不能把训练 snapshot 的
高成功率当成完整任务泛化。

## 6. 策略与 RLinf 的实现门槛

现有 RLinf RoboTwin `use_custom_reward` 路径实际计算的是
`reward_coef * termination`，没有上述稠密奖励。更关键的是，Panthera 的 OpenVLA-OFT 使用
连续 L1 action head，当前补丁在该分支把 `chunk_logprobs` 置零；官方 PPO/GRPO 配置却是
token-level log-prob。直接启动不会给连续动作头产生有效策略梯度。

在任何长训练前必须完成：

1. 为 25×7 连续动作建立可采样且可求 log-prob 的分布，优先采用围绕冻结 SFT 均值的
   有界 Gaussian/tanh 残差；
2. 第一轮只训练残差头和 critic，冻结视觉/VLA 主干；先做 gripper residual 诊断，再开放
   有界 7 维残差；
3. 把 reward、value 和 log-prob 都改成 action-level，并用双 rank 测试确认策略梯度非零且
   同步；
4. PPO 先进行 critic warmup；策略损失保留相对 SFT 基准的 KL 或残差约束；
5. rollout buffer 保留连续查询配对信息、真实执行历史和旧 chunk 有效 mask，并对
   `h1/h20`、episode 边界、提前终止、过期尾部和乱序 minibatch 做对齐单测；
6. 用专家、过早释放、到位未释放、槽外丢失、反复开合和成功沉降六类脚本轨迹单测 reward。

PPO 是首轮候选，因为 VLA-RL 与当前 RLinf 都有对应链路；若连续 PPO 接口代价过高，可用
TD3/SAC 训练同一个有界残差头作为工程备选。GRPO 需要同一初始状态的组内回报存在有效方差，
且同样依赖连续动作 log-prob，不是绕过该门槛的捷径。

## 7. 验收指标与停止条件

每组至少使用三个训练 seed，并分别报告：

- 完整任务成功率及置信区间；
- 有效夹持率、给定有效夹持后的搬运到位率；
- 合法释放率、槽外提前释放率、到位仍夹持率；
- 圆柱被撞倒/推出率和不可恢复失败率；
- 释放后稳定入槽率，而不是只看夹爪开度；
- 六关节动作变化、碰撞冲量、残差幅值和相对 SFT 的 KL；
- 同一绝对时刻的重叠预测 MAE/Huber、chunk 边界 jerk、动作被新观测修订的幅度，以及
  夹爪释放触发延迟；
- release arena 各初始状态层的成功率、完整任务样本效率和推理延迟。

长训练只有在 reward 单测、专家回放得分排序、连续 log-prob/DDP smoke、重叠对齐单测、
固定 SFT 基线复现五道门都通过后才能启动。训练 checkpoint 仍按固定预算保存，并用独立
闭环 rollout 选模；
不使用专家状态验证 L1 选模，也不因为单次视频成功提前宣布收口。

## 8. 当前建议

先修复连续 log-prob、chunk 奖励归因时刻和持续成功判据，再实现 `R1/R2/R3` 共用的 reward
evaluator、release arena 以及连续残差策略。随后加入正确对齐的 `L_overlap` 和旧 chunk
历史条件，用 `R2-C0/C1/C2` 隔离它们对抓取前抖动的作用；只有 `C2` 不损害释放时才测试
夹爪一致性 `C3`。首个有效奖励
实验运行 `R0/R1/R2`；`R3` 只在前两者无法学习时作为解释性上界。这个顺序能分别回答
“RL 是否从结果中学会释放”“跨 chunk 正则是否降低抖动”和“工程师写明阶段是否必要”，
同时最大限度保护 `step 75000` 已有的搬运能力。
