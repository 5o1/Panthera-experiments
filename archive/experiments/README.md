# Historical experiment entries

One-off entry points from earlier experiment generations, kept because they are
the only record of how a particular run was launched, and moved here because
none of them is referenced by any current document and their presence in
`tools/` made it impossible to see which entries are live.

They are not maintained and are not expected to run: they reference datasets,
models and overlay paths from before the 2026-09-19 restructure. Read them as
history; to reproduce a result, use the current pipeline together with the
dataset's own `dataset.json` and the checkpoint's `training.json`, which record
what those runs would have had to be told by hand.
